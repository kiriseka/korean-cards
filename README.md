# Korean Cards

A personal, offline Korean vocabulary app for Android: word cards with Anki-style spaced repetition (FSRS), 2,492 beginner (초급) words from the National Institute of Korean Language's Basic Korean Dictionary, and Korean pronunciation through the phone's text-to-speech.

## Using it

- **Today**: what's due. Tap **Study**: the card shows the Korean word (it speaks it), tap to flip, then rate **Again / Hard / Good / Easy**. Each button shows when you'll see the card next.
- **Words**: search in Hangul or English, filter by New/Learning/Known/Starred, open a word to star it, add a note, suspend it or reset it. **Add word** for words you meet elsewhere — they become your next new cards.
- **Stats**: known words, streak, 30-day retention and reviews per day.
- **Settings**: new words per day (default 10), review cap, English→Korean reverse cards, auto-play and speech speed, daily reminder, theme, backup export/import.

The study day rolls over at 4am.

## Phone setup

1. **Korean voice**: Settings → System → Languages → Text-to-speech output → Google (Speech Recognition & Synthesis) → Install voice data → 한국어. Without it the app works silently and shows a banner.
2. **Install the app** — either:
   - USB: enable Developer options (tap *Build number* 7 times) → USB debugging, plug in, then `flutter run --release` (or `flutter install` after a build).
   - Or run `flutter build apk --release --split-per-abi`, copy `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk` (~21 MB, right for almost every modern phone) to the phone and open it (allow "Install unknown apps" for your file manager).

## Development

Toolchain on this PC: Flutter at `C:\src\flutter` (on the user PATH), Android SDK at `C:\Android\Sdk`, JDK from Android Studio (`flutter config --jdk-dir`).

```bash
flutter pub get
dart run build_runner build      # after changing lib/data/db.dart
flutter test
flutter run                      # phone connected over USB
flutter build apk --release
```

Layout: `lib/data` (drift database, word import), `lib/srs` (FSRS wrapper, session order), `lib/features/*` (screens), `lib/services` (TTS, reminder, backup).

### Rebuilding the word list

`assets/data/words.json` is generated by `tools/build_words.py` from the official KRDict download (krdict.korean.go.kr → 사전 내려받기 → JSON). Unzip it into the project root (the folder is git-ignored) and run:

```bash
python tools/build_words.py                 # 초급 only
python tools/build_words.py --levels 초급,중급
```

On next launch the app imports changed words; progress, stars and notes are kept.

### Release signing

Updates install over the old app only if they're signed with the same key. Create one once and **keep it safe** (back it up outside this folder):

```bash
keytool -genkey -v -keystore C:/Users/<you>/korean-cards.jks -keyalg RSA -keysize 2048 -validity 10000 -alias korean-cards
```

Then create `android/key.properties` (git-ignored):

```
storePassword=...
keyPassword=...
keyAlias=korean-cards
storeFile=C:/Users/<you>/korean-cards.jks
```

Until that file exists, release builds are signed with the debug key.
